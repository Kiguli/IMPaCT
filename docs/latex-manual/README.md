# IMPaCT User Manual — LaTeX + PDF

`impact.pdf` is the compiled user manual (the full Sphinx docs: feature manual,
tool comparisons, ARCH benchmark walkthroughs, getting started, API). `impact.tex`
plus the `sphinx*.sty` support files are the LaTeX sources generated by Sphinx.

Regenerate from the Markdown/RST sources in `docs/`:

```bash
pip install -r docs/requirements.txt
sphinx-build -b latex docs docs/_build/latex
cd docs/_build/latex && latexmk -pdf impact.tex
```

Requires TeX Live (`texlive-latex-extra`, `texlive-fonts-recommended`, `tex-gyre`,
`latexmk`). The Unicode-to-LaTeX mappings live in `docs/conf.py` (`latex_elements`).
